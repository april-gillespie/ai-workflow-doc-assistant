# Architecture Overview

This project demonstrates an AI-assisted document review workflow.

## Process

1. User submits document.
2. Document is provided to an LLM.
3. Structured review prompt is applied.
4. LLM generates feedback.
5. Human reviewer evaluates recommendations.
6. Final decisions remain with the human reviewer.

## Current Scope

- Synthetic sample data only
- Prompt-driven review
- Structured feedback generation
- Human-in-the-loop validation

## Future Scope

- API integration
- Multiple document formats
- Automated report generation
